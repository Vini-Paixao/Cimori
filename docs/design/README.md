contem imagens geradas pelo renderizador Rust com dados de teste; nao sao capturas da ilha
instalada. A versao instalada deve ser validada no monitor do usuario.

[cimori-visual-assets/SOURCES.md](cimori-visual-assets/SOURCES.md). A Inter e a assinatura Cimori
vem dos assets existentes. As imagens `before-*.png` documentam o renderizador anterior.
