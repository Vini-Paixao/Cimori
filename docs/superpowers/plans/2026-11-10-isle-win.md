# `isle-win` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `isle-win`, an ultra-lightweight native Windows 11 top Dynamic Island & AI Agent Control Center cross-compiled from Fedora Linux, replacing the Windhawk `Mac Island & Dock` top pill and bridging Claude Code, Codex, and OpenCode Go between Fedora and Windows over LAN/Tailscale.

**Architecture:** Four-crate Cargo workspace (`isle-core`, `isle-render`, `isle-platform-win`, `isle-ai`) plus a unified root binary (`isle-win`) that runs as the multi-monitor Win32 `UpdateLayeredWindow` + `tiny-skia` pill on Windows 11 and as the CLI/Hook/Quota bridge (`--fedora-bridge`) on Fedora Linux. All domain logic, rendering into BGRA framebuffers, hit-testing, config importing, and HTTP hook/quota bridging are 100% testable on Fedora Linux while cross-compiling cleanly to `x86_64-pc-windows-gnu`.

**Tech Stack:** Rust (2021/2024 edition), `tokio`, `serde`/`serde_json`, `reqwest` (`rustls-tls`), `tiny-skia`, `ab_glyph`, `windows` (v0.58+ Win32/WinRT APIs under `#[cfg(windows)]`), MinGW-w64 (`x86_64-pc-windows-gnu`) for zero-C++-friction Linux→Windows cross-compilation.

**Spec:** `docs/superpowers/specs/2026-11-10-isle-win-design.md`

## Global Constraints

- **RAM & CPU target:** ~8–15 MB RAM, 0% CPU and 0 FPS when `PillGeometry::is_settled()` is `true`.
- **Cross-compilation:** Must compile on Fedora Linux for both native Linux (`cargo test --workspace` and `--fedora-bridge`) and Windows 11 (`cargo build --release --target x86_64-pc-windows-gnu`) with zero external C++ SDK dependencies.
- **Multi-monitor & visual defaults (from `Mac Island & Dock 2026-11-10.txt`):** Monitors `\\.\DISPLAY1` and `\\.\DISPLAY6`, top-center (`X=50%`, `Y=0`, `gap=6px`), opaque dark color `#1C1C1E` (decimal BGR/RGB `1842206`), notch curve `75`.
- **AI Providers & Native Reset Alert:** Claude Code (`claude` CLI login), Codex (`codex` CLI login), and OpenCode Go (API key). Must fire native quota warnings at **80%** and **95%** and a native **"Claude de volta!"** / **"Codex de volta!"** alert when `now >= reset_at` (replacing manual alarms).
- **Hook Safety:** Hook requests to `:47830/api/hook` must never hang Claude Code/Codex if `isle-win.exe` is unreachable, in DND mode, or fullscreen; connection timeout must fall back immediately so the terminal prompt continues normally.

## Review Focus

1. **Windhawk Backup Escaped Newlines & Tab Delimiters:** `Mac Island & Dock 2026-11-10.txt` stores multi-line values using literal `\n` and `\t` escape sequences on a single line (e.g., `smonitorPlaces=500\t0\t\\\\.\\DISPLAY1\n500\t0\t\\\\.\\DISPLAY6\n` and `strayPinned=...`). Parser must unescape `\t`, `\n`, and `\\` before splitting. (Pinned in Task 1 tests).
2. **Repeated Quota Reset Notifications:** Polling quota after `now >= reset_at` must trigger the `"Claude de volta!"` alert **once** per reset cycle, not on every subsequent poll tick. (Pinned in Task 2 tests).
3. **Password Manager Clipboard Leak:** Clipboard updates originating from `1Password`, `Bitwarden`, `KeePass`, or `KeePassXC` (or marked excluded from history) must be rejected by `ClipboardShelf::push_entry`. (Pinned in Task 3 tests).
4. **Click-Through Outside Dynamic Pill Bounds:** Mouse coordinates inside the `580x380` overlay canvas but outside the current spring-interpolated `(width, height)` rectangle (accounting for `gap = 6.0`) must return ` false` in `point_inside_pill` (`HTTRANSPARENT`), otherwise the invisible canvas blocks clicks on browser tabs at the top of the screen. (Pinned in Task 4 tests).
5. **Unreachable Windows Pill or DND Mode During `PermissionRequest` Hook:** When `isle-win` is in DND mode or the user does not respond before hook timeout, `POST /api/hook` must return `{"action": "fallback"}` with HTTP 200 (never hanging or crashing the agent). (Pinned in Task 6 tests).
